# Satoshi font and license reference

V4 uses official **Satoshi Variable** at weight 600 only as the construction base for the corrected outlined wordmark. Every reusable V4 master contains paths rather than a distributed font file or live text.

- Official family page: <https://www.fontshare.com/fonts/satoshi>
- Official Fontshare family metadata: <https://api.fontshare.com/v2/fonts?slug=satoshi>
- Official Fontshare license: <https://www.fontshare.com/licenses/itf-ffl>

Any future production use of Satoshi as a live interface font must verify then-current official license terms and bundle the required official files and notices. That work is outside this candidate-only task.
