# Satoshi font license reference

## Candidate-only use

The `pulso` glyphs in the SVG candidates were converted to vector paths from **Satoshi Medium**. No Fontshare font software is bundled in this candidate package, and no application font integration is authorized by this package.

## Official source

- Font family: <https://www.fontshare.com/fonts/satoshi>
- Official Fontshare CSS/API source used for Satoshi Medium: <https://api.fontshare.com/v2/css?f[]=satoshi@500&display=swap>
- Applicable license: ITF Free Font License (FFL) 1.0, 20 January 2021: <https://www.fontshare.com/licenses/itf-ffl>

The official license controls. Fontshare describes the FFL as permitting personal and commercial use, including logo and vector creation, while retaining restrictions on the font software itself and derivative works. Review the current official license before redistributing, integrating, or approving any candidate.
