# Satoshi font and license reference

The V3 wordmark candidate was traced from **Satoshi Variable** at weights 600 and 700, then converted to SVG paths. This directory contains no distributed Satoshi font file and no live text.

- Official family page: <https://www.fontshare.com/fonts/satoshi>
- Official Fontshare CSS endpoint used to identify the family: <https://api.fontshare.com/v2/css?f[]=satoshi@700&display=swap>
- Official Fontshare family metadata endpoint: <https://api.fontshare.com/v2/fonts?slug=satoshi>
- Official Fontshare license: <https://www.fontshare.com/licenses/itf-ffl>

Before any production use of Satoshi as a live interface font, verify the then-current official license terms and retain the required attribution or notices. The outlined candidate artwork itself is still pending visual approval.
