# Logo lettering and font reference

The approved V5 logo wordmark is custom directly traced vector lettering. It contains no live font, embedded font file, or Satoshi geometry. No font license is required to use this approved logo artwork.

Satoshi is separate application interface typography only. If it remains in use for the interface, follow UI-0001’s requirement to bundle the required official Fontshare files and applicable license text; do not treat this logo directory as a Satoshi distribution.
